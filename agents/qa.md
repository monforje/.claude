| Уровень + Тип | Агент | Когда выбирать |
| --- | --- | --- |
| Модульный + Функциональное | `unit` | Изменена одна функция/метод, нет внешних вызовов |
| Интеграционный + Функциональное | `integration` | Изменено взаимодействие модулей/БД/очередей |
| Интеграционный + Функциональное | `api` | Изменён endpoint, контракт, бизнес-логика на уровне API |
| Любой + Функциональное (стратегия) | `regression` | Есть риск поломки существующего функционала |
| Системный + Функциональное | `e2e` | Изменён полный пользовательский сценарий |
| Системный + Нефункциональное (Performance) | `load` | Нужна проверка под нагрузкой, поиск bottlenecks на уровне системы |
| Модульный/Компонентный + Нефункциональное (Performance) | `profiling` | Нужно найти узкое место в конкретном участке кода |
| Системный/Код + Нефункциональное (Security) | `security` | Нужна проверка уязвимостей, compliance, пентест |
| Системный + Нефункциональное + Функциональное (GUI) | `usability-ui` | Изменён интерфейс, поток, визуал, нужен UX-анализ |
