| Уровень + Тип | Агент | Когда выбирать |
| --- | --- | --- |
| Модульный + Функциональное | `unit.md` | Изменена одна функция/метод, нет внешних вызовов |
| Интеграционный + Функциональное | `integration.md` | Изменено взаимодействие модулей/БД/очередей |
| Интеграционный + Функциональное | `api.md` | Изменён endpoint, контракт, бизнес-логика на уровне API |
| Любой + Функциональное (стратегия) | `regression.md` | Есть риск поломки существующего функционала |
| Системный + Функциональное | `e2e.md` | Изменён полный пользовательский сценарий |
| Системный + Нефункциональное (Performance) | `load.md` | Нужна проверка под нагрузкой, поиск bottlenecks на уровне системы |
| Модульный/Компонентный + Нефункциональное (Performance) | `profiling.md` | Нужно найти узкое место в конкретном участке кода |
| Системный/Код + Нефункциональное (Security) | `security.md` | Нужна проверка уязвимостей, compliance, пентест |
| Системный + Нефункциональное + Функциональное (GUI) | `usability-ui.md` | Изменён интерфейс, поток, визуал, нужен UX-анализ |
