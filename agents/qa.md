| Уровень + Тип | Subagent Path | Когда выбирать |
| --- | --- | --- |
| Модульный + Функциональное | [qa-unit](./qa/qa-unit.md) | Изменена одна функция/метод, нет внешних вызовов |
| Интеграционный + Функциональное | [qa-integration](./qa/qa-integration.md) | Изменено взаимодействие модулей/БД/очередей |
| Интеграционный + Функциональное | [qa-api](./qa/qa-api.md) | Изменён endpoint, контракт, бизнес-логика на уровне API |
| Любой + Функциональное (стратегия) | [qa-regression](./qa/qa-regression.md) | Есть риск поломки существующего функционала |
| Системный + Функциональное | [qa-e2e](./qa/qa-e2e.md) | Изменён полный пользовательский сценарий |
| Системный + Нефункциональное (Performance) | [qa-load](./qa/qa-load.md) | Нужна проверка под нагрузкой, поиск bottlenecks на уровне системы |
| Модульный/Компонентный + Нефункциональное (Performance) | [qa-profiling](./qa/qa-profiling.md) | Нужно найти узкое место в конкретном участке кода |
| Системный/Код + Нефункциональное (Security) | [qa-security](./qa/qa-security.md) | Нужна проверка уязвимостей, compliance, пентест |
| Системный + Нефункциональное + Функциональное (GUI) | [qa-usability-ui](./qa/qa-usability-ui.md) | Изменён интерфейс, поток, визуал, нужен UX-анализ |
