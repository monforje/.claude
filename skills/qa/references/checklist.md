# Чек-лист краевых случаев

Проходить по изменённым функциям. Не все пункты применимы — пропускай нерелевантные, но осознанно.

## Входные данные

- [ ] `null` / `undefined` / `None` в каждом аргументе
- [ ] Пустая строка, пустой массив, пустой объект
- [ ] Один элемент вместо многих
- [ ] Очень большой вход (проверить сложность: нет ли O(n²) на горячем пути)
- [ ] Отрицательные числа, ноль, дробные там, где ожидались целые
- [ ] Строки: Unicode, эмодзи, переводы строк, ведущие/хвостовые пробелы
- [ ] Значения, ломающие парсинг: кавычки, обратные слэши, разделители формата

## Границы

- [ ] Первый и последний элемент коллекции
- [ ] Индекс `length` и `length - 1` (off-by-one)
- [ ] Ровно на пределе лимита, лимит + 1
- [ ] Переполнение целого, потеря точности float
- [ ] Границы дат: смена суток, високосный год, переход часового пояса

## Ошибки и отказы

- [ ] Внешний вызов возвращает ошибку — обработана или проглочена?
- [ ] Таймаут внешнего вызова
- [ ] Исключение в середине операции — не осталось ли состояние наполовину изменённым?
- [ ] Сообщение об ошибке содержит достаточно контекста для диагностики
- [ ] Ошибка не утекает наружу с секретами (токены, пути, PII)

## Состояние и конкурентность

- [ ] Повторный вызов с теми же аргументами (идемпотентность)
- [ ] Два параллельных вызова — гонка за общий ресурс
- [ ] Вызов до инициализации / после освобождения ресурса
- [ ] Утечка: закрываются ли файлы, соединения, подписки
- [ ] Кэш: инвалидируется ли при изменении источника

## Контракт

- [ ] Изменилась сигнатура — обновлены ли все вызывающие (`grep` по имени)
- [ ] Изменился формат ответа API — ломает ли клиентов
- [ ] Изменилась схема данных — есть ли миграция и обратная совместимость
- [ ] Удалено публичное имя — не осталось ли импортов

## Безопасность

- [ ] Пользовательский ввод попадает в SQL / shell / путь к файлу / HTML
- [ ] Проверка прав выполняется на сервере, а не только в UI
- [ ] Секреты не попали в код, логи, сообщения об ошибках

## Тесты

- [ ] Новый тест падает без фикса (проверено запуском)
- [ ] Тест не зависит от порядка выполнения и текущего времени
- [ ] Тест проверяет поведение, а не реализацию
